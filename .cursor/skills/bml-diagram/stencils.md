## Common Icon Code Patterns

### By Category

**Servers and Infrastructure**
- `applicationServer` (uubmlitstuff)
- `webServer` (uubmlitstuff)
- `database` (uucloudmongodboperator)

**Operations**
- `command` (uuappcommon) - API endpoints
- `activity` (uuappcommon) - Process steps
- `activityState` (uuappcommon) - States

**Applications**
- `uusubapp` (uuappcommon)
- `product` (uuplus4umall)
- `workspace` (uuappcommon)

**Data**
- `document` (uuappcommon)
- `uuFls` (uufls)

## Usage Examples

### Server Icon
```json
{
  "sourceUuBmlStencil": "uubmlitstuff",
  "uuBmlIconCode": "applicationServer"
}
```

### Command Icon
```json
{
  "sourceUuBmlStencil": "uuappcommon",
  "uuBmlIconCode": "command"
}
```

### External Product
```json
{
  "sourceUuBmlStencil": "uuplus4umall",
  "uuBmlIconCode": "product"
}
```

### Activity/Process Step
```json
{
  "sourceUuBmlStencil": "uuappcommon",
  "uuBmlIconCode": "activity"
}
```
